# Saved Templates

This folder is the suggested place to save your invoice layouts.

When you click **Save Template** in the app for the first time, your browser
will ask you to pick a folder — choose **this `templates` folder**. Every
save after that (for the rest of your browser session) will write straight
into this folder with no dialog box.

If your browser doesn't support that (Firefox and Safari don't yet), the
app will fall back to a normal download into your Downloads folder instead
— you can then move the file here yourself if you'd like to keep it
organized with the project.

Use **Load Template** in the app and pick a `.json` file from this folder
to reopen a saved layout.
